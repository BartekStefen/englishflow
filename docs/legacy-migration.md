# Migracja starego HTML

Odczytano plik „Mój angielski_ system nauki.html” przekazany przez właściciela. Zachowano 12 tematów tygodniowych, wcześniejszą i późniejszą bibliotekę odnośników, 13 rozbudowanych opisów czasów i linki do polskich wyjaśnień, przykłady z podziałem składni oraz słowniczek terminów. Dodano 23 brakujących adresów; biblioteka ma teraz 102 pozycji. Słownictwo Oxford pozostaje pobierane z dotychczasowej aplikacji, bez ponownej publikacji cudzych nagrań i definicji.

Historyczny plan zakładał start 12.10.2026 i cel A1/A2; nowy start planu użytkownik wybiera sam. Nie przenosimy tego celu jako rzekomej diagnozy jego aktualnego poziomu. Linki wyszukiwania nadal są oznaczane jako wyszukiwanie.
